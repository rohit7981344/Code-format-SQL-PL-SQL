# Changelog

## 0.1.0
- First release: SQL Developer-style formatting for SQL and PL/SQL.
- SELECT / INSERT / UPDATE / DELETE / MERGE / WITH, joins, subqueries, CASE.
- PL/SQL blocks, procedures, functions, packages, triggers, IF / LOOP / CASE / EXCEPTION.
- Settings for keyword case, identifier case, indent size, tabs, comma position, AND/OR breaks, blank lines.
- Safety check: code is never changed beyond whitespace and letter case.
